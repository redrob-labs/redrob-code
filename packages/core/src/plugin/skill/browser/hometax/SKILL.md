# 홈택스 (조회 전용)

도구: `open_page`, `read_page`, `click`, `type_text`.

이 스킬은 조회만 한다. 신고서 작성·제출, 세금 납부, 정보 수정, 동의·신청 버튼("제출", "신고",
"납부", "신청", "동의")은 어떤 경우에도 누르지 않는다. 사용자가 제출을 부탁해도 화면을 열어 둔 채
직접 누르도록 안내한다.

1. `open_page`로 `https://www.hometax.go.kr/`을 연다. 로그인은 공동·금융인증서나 간편인증이라
   대신할 수 없다. 로그인 화면이면 사용자에게 직접 로그인해 달라고 하고 멈춘다.
2. 로그인 뒤에는 상단 검색 칸에 `type_text`로 메뉴 이름을 넣는 것이 가장 빠르다:
   "현금영수증 사용내역", "전자세금계산서 목록조회", "납부내역 조회", "신고서 조회".
3. 조회 화면에서 기간을 고르고 "조회하기"만 `click`한다. 결과는 `read_page`로 읽어 기간, 건수,
   합계 금액을 정리한다.
4. 화면이 팝업이나 보안 프로그램 설치를 요구하면 그 사실을 사용자에게 전하고 멈춘다.

주민등록번호 같은 개인정보는 답에 옮겨 적지 않는다.
